# P2 기획서 — 역할 기반 LMS

**제출 문서: 기획서**  
**구현 루트**: `p2/backend`, `p2/frontend` (실행 방법은 저장소 `p2/README.md`)

---

## 1. 목표 및 범위

| 항목 | 내용 |
|------|------|
| **주제** | 관리자·강사·학생 역할이 분리된 온라인 강의(LMS) |
| **인증** | JWT(Bearer), 역할별 API 가드 |
| **학생** | 공개 강의 탐색, 장바구니, 수강신청·취소, 수업 시청(진도·이어보기), Q&A, 피드백(첨부·스레드) |
| **강사** | 대시보드, 강의 CRUD·공개 설정, 커리큘럼(JSON)·썸네일, 프로필·배너, 업로드, 학생 피드백 응대 |
| **관리자** | 통계, 전체 회원·역할, 전체 강의(비공개 포함) |
| **제외** | 실 결제(PG), CDN 스트리밍, 운영 모니터링·알림 |

---

## 2. 기술·운영 요약

- **백엔드**: NestJS 10, TypeORM, PostgreSQL, bcrypt, Passport JWT  
- **프론트**: React 18, Vite, React Router, Redux(Toolkit) 일부  
- **API**: `/api/v1` 접두사, CORS·Vite 프록시로 프론트와 연동  
- **포트**: 백엔드 `PORT`(기본 3000, `.env`), 프론트 개발 5174  

---

## 3. 역할별 기능 요약

### 3.1 학생

- 강의 목록·상세(비로그인 조회 가능), 장바구니, 간이 일괄 수강신청(결제 시뮬레이션)
- 내 강의실: 진도율·수료 배지·이어보기
- 수업 듣기: HTML5 video, 재생 속도, 목차, **서버 진도 저장**(약 0.5초 디바운스, 90% 완료 처리)
- 강의별 Q&A(질문 CRUD 본인, 답변), 피드백 신청·대화 스레드

### 3.2 강사

- 내 강의 목록·생성·수정·삭제, 공개 여부, 커리큘럼 편집(에디터 UI)
- 이미지/영상 업로드 → 로컬 디스크 + `/api/v1/files/...` URL
- 학생 피드백 목록·상태 변경·메시지

### 3.3 관리자

- 사용자 수·강의 수 등 통계
- 사용자 목록·역할 변경
- 전체 강의 목록(비공개 포함)
