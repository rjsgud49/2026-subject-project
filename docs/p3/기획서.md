# P3 기획 요약

## 목표

P2 LMS를 **운영 가능한 서비스** 수준으로 확장한다.

## 범위

1. **결제** — 나이스페이 샌드박스, 주문·수강 연동, pending 24시간 만료
2. **알림** — 사용자 구독(이메일/Discord), 이벤트 dispatch
3. **Webhook** — 관리자 등록 URL로 JSON POST, HMAC `X-P3-Signature`
4. **감사·메트릭** — 역할 변경 등 audit, HTTP 요청/오류 카운터
5. **학습노트** — `p3_study_notes`, enrollments API
6. **내 강의실** — 강의 / 학습노트 / Q&A 탭

## 이벤트 타입

- `payment_success`
- `enrollment`
- `feedback_answered`
- `qna_answer`
- `pending_feedback_reminder` (스케줄)

## 주요 API

| 메서드 | 경로 | 설명 |
|--------|------|------|
| GET | `/ops/events` | 이벤트 목록 |
| GET/POST/DELETE | `/notifications/subscriptions` | 알림 구독 |
| GET | `/admin/ops/metrics` | 운영 메트릭 |
| GET | `/admin/ops/audit-logs` | 감사 로그 |
| GET/POST/DELETE | `/admin/webhooks` | Webhook CRUD |
| PUT | `/enrollments/:id/videos/:videoId/note` | 학습노트 저장 |

## 프론트 경로

- `/settings/notifications` — 알림 구독
- `/admin/ops` — 메트릭·로그·Webhook
- `/dashboard` — 3탭 강의실
