# 개발계획서 — P2 LMS

## 1. 개요

| 항목 | 내용 |
|------|------|
| **프로젝트명** | P2 — 역할 기반 LMS (관리자·강사·학생) |
| **범위** | JWT 인증, 역할 가드, 강의·수강·장바구니·진도·Q&A·피드백·파일 업로드, 관리자/강사/학생 UI |
| **산출물** | `p2/backend`, `p2/frontend`, 본 `docs/p2/submit` 문서 세트 |
| **저장소 경로** | 과제 루트의 `p2/` |

---

## 2. 개발 단계 (권장 순서)

| 단계 | 활동 | 산출물 |
|------|------|--------|
| 1 | 요구·ERD·API 초안 확정 | 기획서, 요구사항명세서, erd.md, api.yml |
| 2 | 백엔드: 사용자·JWT·역할, 코어 엔티티 | Nest 모듈, 엔티티 `p2_*` |
| 3 | 백엔드: 공개 강의, 장바구니, 수강, 진도, Q&A | REST API |
| 4 | 백엔드: 강사·관리자·피드백·업로드 | teacher/admin/feedback/files |
| 5 | 프론트: 인증·라우팅·역할별 레이아웃 | 페이지·Redux/API 연동 |
| 6 | 통합·시드·문서 동기화 | seed.ts, submit 문서 최종 |

---

## 3. 마일스톤 (완료 기준 예시)

| MS | 기준 |
|----|------|
| MS1 | 로그인·역할 가드·공개 강의 API 동작 |
| MS2 | 학생: 장바구니·수강·진도·Q&A·수강 화면 |
| MS3 | 강사: 강의 CRUD·업로드·프로필 |
| MS4 | 관리자·피드백·파일 서빙 |
| MS5 | 제출 문서·OpenAPI·ERD가 구현과 일치 |

## 4. 개발 스택 및 버전 (구현 기준)

| 구분 | 항목 | 비고 |
|------|------|------|
| 런타임 | Node.js 20 LTS 권장 | |
| 백엔드 | NestJS 10, TypeScript 5 | TypeORM, PostgreSQL |
| 인증 | Passport JWT, bcrypt | |
| 프론트 | React 18, TypeScript, Vite 5 | Redux Toolkit 일부 |
| DB | PostgreSQL 15+ | `DB_NAME` 등 `.env` |
